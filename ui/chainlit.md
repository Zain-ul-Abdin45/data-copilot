# Data Copilot

Ask questions about the company's data in plain words.

- Numbers come from **governed metrics** wherever one exists, and the badge above each answer says so.
- If no metric covers a question, an **ad-hoc SQL** query is used and labelled as not governed.
- Tables and charts are drawn from the returned data, never from the model's wording.
- Open **How this was calculated** under an answer to see the definitions, steps and SQL.

Follow-up questions work ("and by month?").
